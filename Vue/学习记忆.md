## JavaScript 教学文件规则

1. 每个新知识点都在 `02-JavaScript学习/JavaScript知识点示例/` 下建立独立文件夹。
2. 文件夹名称采用“编号-知识点”，编号按照学习顺序递增。
3. 每个知识点至少有一个可直接运行的 `index.html`。
4. 每个案例必须同时包含 HTML 和 JavaScript，不能只给脱离页面的 JavaScript。
5. 需要真实外部数据或模块时，可以添加 `.json` 或 `.js` 配套文件。
6. `JavaScript学习笔记.md` 中每个知识点固定记录：功能点、解决的需求问题、语法讲解、部分案例、完整示例路径。

## Vue 教学文件规则

1. Vue 只使用 `03-Vue学习/vue学习项目/` 这一份 Vite 项目和一份 `node_modules/`。
2. 每个知识点在 `src/lessons/` 下建立独立的 `Lesson.vue`。
3. 根 `src/App.vue` 只负责选择当前正在学习的课程。
4. `Vue学习笔记.md` 中记录知识点是什么、作用、解决的问题、语法和案例。
5. 先学习一个主概念，再进入下一个概念，不把多个指令混在同一课。
6. 多页面项目可以有多个 HTML 入口，每个页面有自己的 `main.js` 和根组件。
