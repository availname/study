线程池执行流程交互演示

Java 并发 05 · 顺序背熟：核心线程 → 队列 → 临时线程 → 拒绝策略
顺序真相：核心满 → 先排队，队列满才建临时线程（不是先开满线程！）

⚠ 无界队列实验：队列容量设 9999 → 点洪峰 → 临时线程永远不建、任务无限堆积——
这正是 Executors.newFixedThreadPool 的 OOM 坑。

① 核心线程（常驻）

② 任务队列 BlockingQueue（演示用有界队列）

③ 临时线程（keepAlive 空闲超时回收）

④ 拒绝区（队列满 + 线程到 max）

CallerRunsPolicy = 提交者自己执行（天然限流回压）；生产自定义：日志 + 落库 + 告警
