线程生命周期交互示意图

Java 并发编程 01 · 点下面的按钮触发事件，观察"小球"（当前线程）在六个状态之间流转
NEWnew 出来没 start
RUNNABLE就绪/运行中
BLOCKED等 synchronized 锁
WAITING死等：wait/join/park
TIMED_WAITING限时：sleep(n)/wait(n)
TERMINATEDrun 结束
知识点：①RUNNABLE 涵盖"就绪+运行中"，是否上 CPU 由调度器决定；②只有 RUNNABLE 可以直接进 TERMINATED； ③WAITING（死等）与 TIMED_WAITING（限时）的差别只是有没有超时参数；④回到 RUNNABLE 后是否真正运行仍取决于调度。
