# 06 · 设计模式（★）✅ 5/5 完成

设计模式的本质不是 23 个名字，而是**"找到变化并封装"**。每一种都配"你已学过的源码实例 + 你自己项目的影子"：

| 篇 | 主题 | 涵盖模式 |
|----|------|---------|
| [01](01-创建型：单例工厂建造者.md) | 创建型 | 单例（DCL/静态/枚举）、工厂（DriverManager/BeanFactory）、建造者（QueueBuilder/ChatClient） |
| [02](02-结构型：代理装饰门面适配器.md) | 结构型 | 代理（AOP）、装饰器（Java IO/RequestWrapper）、门面（ReliableMessagePublisher）、适配器（Feign） |
| [03](03-行为型：策略模板观察者.md) | 行为型 | 策略（拒绝策略/负载均衡）、模板方法（AQS/JdbcTemplate）、观察者（Event/MQ fanout） |
| [04](04-SOLID原则与实战组合.md) | 原则与反模式 | SOLID 五原则 / 秒杀项目模式全家桶复盘 / 什么时候不该用设计模式 |
| [05](05-责任链与状态机.md) | **业务编排骨架** | 责任链（Netty pipeline/Gateway 过滤器/审核管道）/ 状态机（转移表+CAS 双保险）/ 判别口诀 |

学习心法：从"想砸键盘的场景"入手 → 在源码里认亲 → 给自己项目的代码贴标签。
