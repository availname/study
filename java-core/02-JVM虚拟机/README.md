# 02 · JVM 虚拟机

并发解决"怎么让多线程协作"，JVM 解决"程序跑在什么样的地基上"：**内存怎么分配、垃圾怎么回收、代码怎么加载、线上怎么排查**。

这五篇学完你能回答后端面试 JVM 三大板块：
1. 内存区域与对象（堆/栈/元空间、对象怎么建怎么死）
2. 类加载（双亲委派）
3. 垃圾回收（算法/收集器/G1/ZGC）
以及生产实战第四板：**OOM/CPU 飙高怎么排查**（Arthas 实操）。

## 与已有教学的连接

- **虚拟线程**（stage6/01）为什么便宜：栈存在 JVM 管的堆里，不用 OS 分配 MB 级线程栈——先懂 JVM 栈，再懂虚拟线程省了什么
- **GC 停顿** 是所有延迟敏感系统（Redis 教学反复强调的"延迟毛刺"）的 Java 版对应物：GC 一停，全请求排队
- **排查三板斧**（jmap/jstack/Arthas）是 mq-mall/community 上线后出问题时的救命工具

## 环境准备

你的 JDK 21 自带全套诊断工具（jps/jstat/jmap/jstack/jcmd），加上神器 **Arthas**：

```bash
curl -O https://arthas.aliyun.com/arthas-boot.jar    # 官方便捷下载
java -jar arthas-boot.jar                            # 选进程进入，交互式诊断
```

每篇末尾给实操任务，全部可在本机完成（无需服务器）。

开始：[01-运行时内存区域与对象](01-运行时内存区域与对象.md)。
