## 为什么放在"00"（最前面却最后学）

语言基石是**最容易被跳过的知识**——每天都在用，以为都会；但面试一问 HashMap 扩容、fail-fast、类型擦除，立刻露馅。学完并发/JVM 之后再回头看这些，会有"原来如此"的顿悟（比如：学了 AQS 才懂 ConcurrentHashMap 的 CAS+synchronized 组合；学了 GC 才懂为什么要对象池）。
