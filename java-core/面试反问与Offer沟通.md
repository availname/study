# 面试反问与 Offer 沟通（求职软技能篇）

技术答完了，面试官说"**你有什么想问我的吗？**"——这不是客套，是最后一道评分题。技术话术见[简历项目话术](简历项目话术.md)与[模拟面试追问链](模拟面试追问链.md)，本篇覆盖之后的环节：**反问 → 薪资 → 多 offer 决策**。

## 一、反问：一道隐藏的评分题

面试官通过你的反问判断三件事：**你对岗位认真到什么程度、你的关注点层次、你是个什么水平的人**。❌ "没什么想问的"（扣分：不上心）；❌ 一上来就问薪资加班（顺序错了——那是 HR 环节的事）。

### 分层反问清单（挑 2~3 个，按面试官身份选）

| 问谁 | 推荐问法 | 你在探什么 |
|------|---------|-----------|
| 技术面 | "团队现在用的是哪个版本的 Spring/JDK？消息队列和缓存怎么选型的？" | 技术栈新旧——你学的是 Boot 3.2，能直接接住 |
| 技术面 | "这个岗位进来最先接手的是什么模块？" | 活是好活还是维护屎山 |
| 技术面 | "团队怎么做 code review？有没有发布规范和监控告警体系？" | 工程文化——**有 review 的团队成长快**（13 篇讲的东西有没有落地） |
| 技术 leader | "新人前三个月的期望是什么？有导师制吗？" | 培养机制是否真实存在 |
| leader | "团队现在最大的技术挑战是什么？" | 加分反问——把对方拉进深入聊 |
| HR | "晋升机制大概怎么运作？上次晋升答辩是什么时候？" | 晋升是真通道还是画饼 |

**王牌收尾反问**（任何轮次适用）："**基于今天的交流，您觉得我和这个岗位的匹配度还有哪些需要补强的地方？**"——既是学习机会，也传递"我接受反馈"的成熟信号。

### 拿到答案之后：别浪费

面试官说"我们用 RocketMQ"——你能接："事务消息我们项目里用本地消息表解决过类似问题，贵司是原生事务消息还是也做了封装？"——**一问一答间展示知识地图**（[stage6 RocketMQ 专篇](../mq/stage6-RocketMQ专篇/README.md)就是为这一刻准备的）。❌ 只回"好的了解了"。

## 二、薪资沟通：三句话原则

**1. 报价报区间，下限是你真实底线。**
"期望 18~22k"——HR 会按 18 谈。下限报你能接受的，别把真心上限放前面。

**2. 被问当前薪资：如实+结构化。**
"目前 15k×13，含季度绩效平均年包 X 万。"——隐瞒会被背调拆穿；结构化（月薪×月数+奖金+补贴）让对方准确对标你的涨幅。

**3. 议价一次到位，书面为准。**
拿到 offer 后想谈：**一次性**列出理由（另一 offer 对比/当前年包涨幅），礼貌但明确；❌ 反复拉锯（超过一次，HR 会换人谈）。**口头 offer 不算数**——"等邮件"是最稳的一句话。

**涨幅常识**：跳槽合理涨幅 20%~30%；低于 15% 要有别的理由（平台/方向/稳定性）；说不出理由的低薪跳槽，下家还会压价。

## 三、多 Offer 决策：打分表代替纠结

| 维度 | 权重建议 | 问自己 |
|------|---------|--------|
| **成长性** | 30% | 三年后简历上这段经历加分吗？技术栈/业务量/导师 |
| 薪酬包 | 25% | **总包**（现金+奖金+期权按 0 折算）不是月薪 |
| 业务确定性 | 15% | 赛道/盈利模式/这轮裁员为什么轮到或不轮到 |
| 团队与 leader | 15% | 面试时他讲不讲得清方向？反问环节的表现就是样本 |
| 通勤与形态 | 10% | 每天 2.5h 通勤会耗尽你一年的学习时间 |
| 稳定性 | 5% | 试用期比例/五险一金基数（按最低基数交=减薪） |

**先定权重再打分**——纠结的本质是没想清楚自己要什么。应届/1~3 年经验：成长性权重拉满；5 年+：业务确定性和薪酬占比上调。

## 四、时间线管理

- 拿到口头 offer → 争取 1~2 周考虑期 → 用它去催进度慢的流程（"有 offer 在手，期望本周能定"——**真实且合法的催法**）
- 骑驴找马：请假面试说"个人事务"；背调授权后再让现公司知道
- 拒 offer 也要礼貌婉拒并留联系方式——圈子小，三年后可能再遇

## 面试问法（本篇的"面试问法"就是实战本身）

**Q（HR）: 你还有什么想问的？**
A: 反问 2~3 个分层问题（技术栈/接手模块/code review 文化，或 leader 场问新人期望+团队挑战），收尾匹配度反问；薪资只回应结构化报价、区间下限为底线；offer 阶段一次到位议价、等书面。
